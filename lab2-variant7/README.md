# Лабораторная работа №2

Обработка изображений на GPU. Фильтры.

Вариант 7. Выделение контуров. Метод Собеля.

## Компиляция CUDA-кода

```bash
cd lab2-variant7
nvcc lab2.cu -o lab2
```

## Запуск программы

```bash
./lab2
```

На первой строке вводится путь к входному изображению, на второй — к выходному.

## Jupyter Notebook

В файле [`experiments.ipynb`](experiments.ipynb) представлены эксперименты, измерения времени CPU- и GPU-версий и изображения с результатами обработки.

Также используются:

- [`lab2.cu`](lab2.cu) — основная CUDA-программа с фильтром Собеля.
- [`convert.py`](convert.py) — конвертация изображений между PNG и `.data`.
- [`data/`](data/) — входные изображения и данные.
- [`results/`](results/) — изображения после обработки.
- [`report/`](report/) — [`cpu.cpp`](report/cpu.cpp): CPU-версия; [`benchmark.cu`](report/benchmark.cu): бенчмарки.
