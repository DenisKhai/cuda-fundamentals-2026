# Лабораторная работа №3

Классификация изображений на GPU.

Вариант 4. Метод спектрального угла.

## Компиляция CUDA-кода

```bash
cd lab3-variant4
nvcc lab3.cu -o lab3
```

## Запуск программы

```bash
./lab3 < data/04.txt
```

Входные данные: пути к исходному и выходному изображениям, число классов, затем для каждого класса — число обучающих пикселей и их координаты. Номер класса записывается в альфа-канал выходного `.data`; RGB-каналы сохраняются.

## Jupyter Notebook

В файле [`experiments.ipynb`](experiments.ipynb) представлены характеристики компьютера и GPU, сравнение времени CPU и десяти конфигураций GPU по 100 повторениям, выбор лучших конфигураций и примеры изображений «до / после».

Запускайте notebook из папки `lab3-variant4`. Сохранённые замеры читаются из CSV; при отсутствии файлов измерения выполняются автоматически.

## Основные файлы

- [`lab3.cu`](lab3.cu) — основная CUDA-программа.
- [`data/`](data/) — исходные изображения и обучающие выборки в `.txt`.
- [`results/`](results/) — выходные `.data`, карты классов и изображения «до / после».
- [`report/cpu.cpp`](report/cpu.cpp), [`cpu.h`](report/cpu.h) — реализация на CPU.
- [`report/benchmark.cu`](report/benchmark.cu) — измерения CPU и GPU, проверка результатов.
- [`report/run_benchmarks.py`](report/run_benchmarks.py) — сборка бенчмарка и сохранение замеров.
- [`report/device_info.cu`](report/device_info.cu) — получение характеристик GPU.
- [`report/results/`](report/results/) — сохранённые CSV с измерениями времени.
