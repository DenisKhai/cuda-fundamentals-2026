## Jupyter Notebook

В файле [`experiments.ipynb`](experiments.ipynb) реализован воспроизводимый эксперимент для анализа CPU- и GPU-версий алгоритма. В notebook представлены:

- характеристики программного и аппаратного окружения;
- компиляция и запуск последовательной CPU-версии и CUDA-версии;
- измерения времени для разных размеров входных данных и конфигураций CUDA-сетки;
- выбор лучшей из протестированных GPU-конфигураций;
- сравнение времени вычислений на CPU и GPU
